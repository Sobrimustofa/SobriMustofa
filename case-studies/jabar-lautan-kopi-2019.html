Jabar Lautan Kopi 2019 is documented as a major historical production project. The project record supports a clear scope statement: the event was handled end-to-end, from its starting point through completion.

This page intentionally focuses on responsibility and production architecture. Attendance, venue, commercial performance and other scale claims remain unpublished until project documentation is attached.

01 / MY CONTRIBUTION

End-to-end production responsibility.

The strength of this case is connecting planning, production, technical coordination, program considerations and on-ground delivery.

02 / CONTEXT

An event that had to be built, coordinated and delivered as one system.

The project sits within NUSAKARA's Event & Experience / Production portfolio. Its value as a case is not a single deliverable; it is the breadth of responsibility across the event lifecycle.

Concept Planning Production Technical Talent / Program On-Ground Execution Completion.

This is the working architecture reflected in the current portfolio record. Exact sub-scope should be expanded only when project records confirm the individual responsibilities.
